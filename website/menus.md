# Menus

Menus control the links in your website's header and footer. Build a menu from your pages, posts, tours, destinations and custom links, nest items into dropdowns, then assign it to a location.

::: info Where to find it
Console › Website › Appearance › Menus
:::

## Create a menu

1. Go to **Website › Appearance › Menus**.
2. Enter a **New menu name** (for example "Main menu") and choose **Create menu**.
3. Add items from the left column (see below).
4. Under **Menu settings**, tick a **Display location**: **Header menu** or **Footer menu**.
5. Choose **Save menu**.

::: tip No header menu yet?
Until a menu is assigned to the Header menu location, your website shows a set of default links.
:::

## Add items

The **Add menu items** column has a panel for each kind of content:

| Panel | Adds |
|---|---|
| Pages | Your published pages |
| Posts | Blog posts |
| Tours | Individual tours |
| Destinations | Destination landing pages |
| Activities | Activity landing pages |
| Tour categories | Category landing pages |
| Blog categories | Blog category archives |
| Website links | Built-in pages: Home, Tours, Blog, Reviews, All destinations, All activities, All tour categories, Contact, My bookings |
| Custom links | Any address |

Tick items (or **Select all**) and choose **Add to menu**.

For a **custom link**, enter a full address (`https://…`), a path starting with `/`, or a `mailto:` or `tel:` link, plus the **Link text**.

## Arrange items and dropdowns

- Drag items in **Menu structure** to reorder them.
- Drag an item slightly to the right under another to make it a **sub-item**. Sub-items show as dropdowns in the header.
- Or open an item and use **Move**: Up one, Down one, Under *item*, Out from under.

## Edit an item

Open an item to change:

- **Navigation label**: the text visitors see. **Use original title** resets it.
- **Open link in a new tab**.
- **Remove item**.

Items pointing at unpublished content show **Not published** and are hidden on the website until the content goes live.

## Use menus in the header and footer

The header and footer builders can show *any* menu, not only the ones in a location. In the [Theme Builder](/website/theme-builder), add a **Menu** element to the header or a **Menu** widget to the footer and choose **Which menu**.

## Delete a menu

Select it in **Menu to edit**, then choose **Delete menu**. Pages and tours are not affected.
