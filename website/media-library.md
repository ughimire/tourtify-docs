# Media library

The media library holds every photo, video and document you use on your website and tours. Upload once and reuse files anywhere: tour galleries, page content, theme blocks, downloads.

::: info Where to find it
Console › Website › Media
:::

## Upload files

1. Go to **Website › Media** and choose **Upload files**.
2. Drag files onto the drop zone, or choose **Choose files**.
3. Wait for the upload to finish; the new files appear at the top.

Accepted types: **JPG, PNG, WebP, GIF, AVIF, MP4, WebM and PDF**, up to **50 MB each**. Files are checked by their content, not just their name.

::: tip
You can also upload straight from any image or file picker in the console (cover photo, gallery, featured image). Those files land in the library too.
:::

## Find files

- Switch between **Grid view** and **List view**.
- Filter by type: **All media items**, **Images**, **Video**, **Documents**.
- Use **Search media** to find a file by name or title.

## Edit file details

Click a file to open **Attachment details**.

| Field | Use |
|---|---|
| Alt text | Describe the image for people who can't see it, and for Google. Leave empty only if it's purely decorative. |
| Title | Your own label for the file |
| Caption | Optional text shown with the image where supported |
| File URL | Choose **Copy URL** to paste the address elsewhere |

Changes save automatically. Use the arrows to move to the previous or next item.

::: tip Alt text helps SEO
The [SEO score](/website/seo) checks that your cover image has alt text. Set it here once and it is used everywhere the image appears.
:::

## Delete files

1. Choose **Select**, tick the files, then **Delete permanently**.

Deleted files are removed from your storage. Anywhere the file was used will show it as **Missing**, so replace it there first.

## Storage

The top of the screen shows **Storage used** against your plan's allowance. By default the plans include:

| Plan | Storage |
|---|---|
| Starter | 10 GB |
| Growth | 30 GB |
| Scale | 100 GB |

When you reach the limit, new uploads are refused until you delete files or upgrade. See **Settings › Plan & usage**.
