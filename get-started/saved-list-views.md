# Saved list views

Every main list (bookings, enquiries, customers, departures, payments, disputes, invoices, tasks, waivers, reviews,
suppliers, supplier bills, conflicts) has a **Views** menu in its toolbar:

- **Save as new view**: keeps the filters, sort and visible columns under a name.
- **Update** a view after changing its filters; **rename** or **delete** it.
- **Open this list with it**: your default view for that list. Opening the list from the menu then opens that view;
  clearing the filters on the list itself keeps it cleared.
- **Share with the team** and **Team's default** (needs *Share saved list views*, `views.share`; owners and admins).
  Your own default wins over the team's.
- **Copy link to this view**: the link opens the same filters, sort and columns for anyone with access.
- **Columns** (where the list has optional columns) chooses what the table shows; it is part of the view and the link.
